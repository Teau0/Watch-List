# Watch Liste

Suivi personnel des films, séries et animés (vus, en cours, à voir), avec recherche AniList / TVmaze / IMDb, affiches, genres et suivi par saison.

Site statique en un seul fichier (`index.html`), hébergé sur GitHub Pages. La liste est enregistrée dans le navigateur (export/import JSON dans la barre latérale).
